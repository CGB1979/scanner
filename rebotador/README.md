# Rebotador

Esta carpeta es una copia inicial independiente de Scanner_Main para desarrollar la aplicación **Rebotador** sin modificar el Scanner principal.

- **Carpeta de publicación:** `/scanner/rebotador/`
- **URL de la app:** `https://cgb1979.github.io/scanner/rebotador/`
- **Manifest:** `/scanner/rebotador/manifest.json`
- **Service Worker:** `/scanner/rebotador/service-worker.js`
- **Versión propia:** `js/version.js`
- **Cache PWA propio:** `rebotador-<versión>`

Las rutas de los recursos internos siguen siendo relativas para reutilizar la estructura clonada, mientras que el manifiesto y el registro del Service Worker quedan anclados explícitamente al subdirectorio `/scanner/rebotador/`.

# Scanner Web

Scanner web para la gestión y control de vehículos y ubicaciones.

## Descripción

Proyecto web desarrollado para facilitar el registro, control y seguimiento de vehículos mediante una interfaz sencilla y accesible desde un navegador.

## Estructura del proyecto

El proyecto está organizado en diferentes archivos y carpetas para facilitar su mantenimiento y futuras modificaciones.

```text
scanner/
├── index.html
├── css/
├── js/
├── data/
├── img/
└── README.md
```
